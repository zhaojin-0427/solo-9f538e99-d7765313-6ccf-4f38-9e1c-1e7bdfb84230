# 车队精算取数

按**自然月**下载每辆车的可赔天数与计入的索赔号。覆盖规则：

- 合同 `[起日, 止日)`：**起日计入，止日不计**。
- 同一辆车保障期**相接或重叠**自动合并为一段；重叠部分不重复计天。
- 每段**前 30 天为等待期**：等待期内的天数与索赔均从取数结果中扣除。
- 补单把两段接通后，合并为一段、只计一次等待期，后一段原本因等待期被排除的索赔会重新判定。
- 按月取数只做日期差运算，不按天展开多年保障期，也不回读合同。

## 快速开始

```bash
docker compose up --build
# 打开 http://localhost:8000
```

本地直接运行：

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python app.py          # http://localhost:8000
```

数据默认写入 `FLEET_DATA_DIR`（容器内为 `/data`，本地为 `./data`）。可用环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `FLEET_DATA_DIR` | `./data` / `/data` | SQLite 文件所在目录（挂载卷） |
| `FLEET_WAITING_DAYS` | `30` | 每段等待期天数 |
| `FLEET_SECRET_KEY` | dev 值 | Flask session 密钥，生产环境务必修改 |

## CSV 格式

合同（UTF-8，表头必须一致）：

```
合同号,车号,起日,止日
HT-0001,粤A10001,2024-01-01,2024-04-01
```

索赔（`故障日` 可空；空日期的索赔不归入任何月份）：

```
索赔号,车号,故障日
CL-0001,粤A10001,2024-02-10
```

`/` 页面上传后即可在 **按月取数** 页查看/下载；也可在 **车辆明细** 页按编号更正合同或索赔、撤销合同。示例文件在 `samples/`。

## 每月下载

- `/extract?month=YYYY-MM`：页面查看当月结果与汇总。
- `/extract/download?month=YYYY-MM`：下载当月 CSV（UTF-8 BOM，Excel 友好）。
- `/download/current`：下载全部月份结果。

## 数据与一致性

- **原始记录与取数结果同事务生效**：一批（上传/更正/撤销）在 `BEGIN IMMEDIATE` 内先写原始行、再重算派生结果，任一步失败整体回滚，之前的结果仍可下载。
- **每批只重算受影响车辆**：批次日志记录涉及车辆与实际重算车辆；未涉及的车辆结果时间戳不变。
  - 索赔批次复用已合并的保障段，不重建。
  - 仅当车辆的有效合同集合变化时才重建合并段。
- **批次前快照**：每批开始时在**同一事务内**保存当时的取数结果 CSV；失败批次回滚时快照一并消失，因此“可下载的上版结果”始终是最后一次成功提交的状态。

## 代码结构

- `fleet_app/compute.py`：纯日期/整月分摊逻辑（半开区间、合并、等待期、按月裁剪），无 I/O。
- `fleet_app/db.py`：SQLite 存储、CSV 解析、增量重算、导出。
- `app.py`：Flask 路由与页面。
- `tests/test_app.py`：21 个用例，覆盖合并、等待期重判、补单接通、更正/撤销、批次范围、失败回滚与 Web 流程。

```bash
python3 -m pytest -q
```

## 边界说明

- 起止日期按自然日计；跨月天数按日历月实际天数（含闰年 2 月）。
- 时间戳统一 UTC ISO 8601。
- 更正合同/索赔会更新原记录行并生成新批次，便于审计；撤销合同保留原始行（`voided_at`）但不再计入。
- 多次上传同一合同号不会去重，按独立合同参与合并（如需业务上去重，请在导入前处理）。
